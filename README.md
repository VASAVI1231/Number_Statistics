# Number Statistics 🐍

## Project Overview

Number Statistics is a beginner-friendly Python project that
analyses a list of integers.

The program identifies even and odd numbers and finds the
largest and smallest values in the given list.

This project demonstrates the use of Python fundamentals
for simple numerical data processing.

## Objectives

- Identify even and odd numbers.
- Separate even and odd values into different lists.
- Find the largest number in a list.
- Find the smallest number in a list.
- Practise Python loops, conditions, and lists.

## Technologies Used

## Concepts Used

- Variables and Lists

- append()

- min()

## How It Works

1. A list of integers is created.
2. The program iterates through each number.
3. The modulo operator checks whether a number is even or odd.
4. Even and odd numbers are stored in separate lists.
5. The max() function finds the largest number.
6. The min() function finds the smallest number.
7. The results are displayed.

## Sample Input

[12, 7, 3, 18, 5, 20, 9]

## Sample Output

Original Numbers: [12, 7, 3, 18, 5, 20, 9]

Even Numbers: [12, 18, 20]

Odd Numbers: [7, 3, 5, 9]

Largest Number: 20

Smallest Number: 3
